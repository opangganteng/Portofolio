Ringkasan Profesional

Saya merupakan Fresh Graduate S1 Teknik Informatika Universitas Gunadarma (2026) dengan pengalaman praktik di bidang IT Support dan dukungan operasional teknologi informasi. Memiliki pengalaman dalam menangani troubleshooting perangkat keras, perangkat lunak, jaringan komputer, serta server. Terbiasa melakukan instalasi, konfigurasi, dan pemeliharaan perangkat TI, termasuk monitoring CCTV dan penanganan kendala teknis pengguna.

Saya juga memiliki pemahaman dasar administrasi jaringan dan teknologi Cisco, serta kemampuan pendukung dalam pengembangan aplikasi berbasis web menggunakan PHP, Laravel, C# ASP.NET MVC, dan Next.js dengan berbagai sistem basis data. Memiliki kemampuan analitis, problem solving, komunikasi, dan adaptasi yang baik, serta mampu bekerja secara mandiri maupun dalam tim.

Saya memiliki ketertarikan untuk terus mengembangkan kompetensi di bidang IT Support, IT Infrastructure, System Monitoring, dan System Integration, serta berkontribusi dalam menjaga keandalan dan kelancaran operasional teknologi informasi perusahaan.
